# Progress

## Purpose

This directory tracks the implementation progress of NetIntel AI: feature-by-feature status, ownership, associated commits, visual proof, tests, and demo readiness. It is the operational record of what has actually been built, as distinct from what is planned (see `docs/architecture/`, `docs/contracts/`, etc.).

## What Will Eventually Live Here

- `implementation-ledger.md` — the authoritative table of feature status, owner/AI, Git commit, visual proof, test status, and demo readiness
- `visual-evidence-convention.md` — the convention every major feature's visual proof must follow
- Visual progress artifacts (screenshots, side-by-side comparisons, interaction recordings) referenced by the ledger, organized per the naming convention

## Current Status

**Foundation only.** The implementation ledger exists and records the completed prerequisite (P0.x) tasks. No application features have been implemented yet, so no visual evidence exists yet beyond this foundation phase.

## What Must NOT Be Prematurely Decided

- No screenshot, recording, or "visual proof" may be fabricated or placeholder content labeled as real implementation evidence.
- No feature may be marked "demo ready" without a corresponding commit, passing test, and real visual proof.
- Status entries must reflect actual repository state, not intended or aspirational state.
