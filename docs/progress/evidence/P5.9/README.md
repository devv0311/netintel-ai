## Known gap

No interaction **recording** is included. The convention asks for one "where interaction matters", and dossier generation is a multi-step flow, so this is a genuine gap rather than a non-applicable item. Playwright records `webm`, the convention specifies `mp4`/`gif`, and no `ffmpeg` is available on this machine to convert. The multi-step flow is instead evidenced by the ordered stills above (initial → generating → completed → detail → reload → regeneration), and the flow itself is asserted end to end in the spec. Recording it properly is left as follow-up work rather than satisfied with a mislabelled file.
